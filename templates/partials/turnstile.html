{% comment %} Cloudflare Turnstile, wired up once for the whole site. To protect a form, drop this inside it:
and nothing else. This helper takes care of the rest: * Renders the widget lazily, the first time someone focuses a field in that form. Lazy matters because most of our forms live inside modals that are display:none on page load, and a widget rendered into a hidden container does not reliably solve. * Blocks submission until a token exists, using a capture-phase listener so it runs BEFORE the page's own submit handler. That means the existing handlers did not have to change - Turnstile adds its own hidden cf-turnstile-response input, which their FormData(form) already picks up. * Resets the widget after each submit, because a token is single use. {% endcomment %}
